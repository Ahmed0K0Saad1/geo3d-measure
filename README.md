# Geo3D Measure — قياس المسافات على كرة أرضية 3D

تطبيق ويب تفاعلي بكرة أرضية ثلاثية الأبعاد (CesiumJS) لتثبيت نقاط في أي مكان بالعالم — بموقعك الحقيقي، أو بالإحداثيات، أو بالبحث — وقياس المسافات والمساحات بينها بطرق جيوديسية موثقة، مع واجهة عربية/إنجليزية وتصدير النتائج.

| البند | القيمة |
|---|---|
| الحالة | 🚧 **P1 — التهيئة التقنية** (جارية) |
| المالك | أحمد (مهندس نظم معلومات جغرافية) |
| آخر تحديث | 2026-10-19 (الجلسة 2) |
| النطاق المستهدف | v1.0 — `docs/REQUIREMENTS.md` |

## التقنيات المعتمدة
CesiumJS · React + TypeScript · Vite · Zustand (مقترح) · Dexie/IndexedDB (مقترح) · proj4js + mgrs · react-i18next · Vitest

> ما هو "مقترح" يُعتمد نهائيًا في مرحلته الموثقة داخل `docs/DECISIONS.md`.

## بروتوكول استئناف الجلسات (أي شات جديد يبدأ من هنا)
1. اقرأ `docs/STATE.md` — ستعرف فورًا المرحلة الحالية والمهمة التالية.
2. افتح المهمة المطلوبة في `docs/ROADMAP.md` (بالرقم، مثلًا `T1.2`) واقرأ خطواتها ومعيار إنجازها.
3. راجع القرارات المرتبطة (بالأرقام `ADR-0xx`) في `docs/DECISIONS.md`.
4. نفّذ المهمة — مع شرح كل خطوة قبل إنشاء أي ملف، والانتظار للموافقة.
5. حدّث `STATE.md` و`ROADMAP.md`، وسجّل أي قرار جديد في `DECISIONS.md`، ثم التزام Git واحد واضح الرسالة.

## قواعد العمل (ملخص)
- ❌ لا يُنشأ أي ملف ولا يُنفَّذ أمر مؤثر قبل شرحه والموافقة عليه.
- ✅ كل مهمة تنتهي بتحديث التوثيق + التزام Git منفصل.
- ✅ كل قرار تقني يُرقَّم في `DECISIONS.md` مع السبب والبدائل.
- ✅ التواصل بالعربية مع المصطلحات التقنية بالإنجليزية.
