# REQUIREMENTS.md — متطلبات المنظومة v1.0

> **الحالة:** معتمدة من المالك (2026-10-19). أي تعديل يتطلب قرارًا جديدًا (ADR) + تحديث هذا الملف و`STATE.md`.

## 1) الرؤية
تطبيق ويب تفاعلي بكرة أرضية ثلاثية الأبعاد يتيح تثبيت نقاط في أي مكان بالعالم (بالموقع الحقيقي، أو بإدخال إحداثيات، أو بالبحث)، وقياس المسافات والمساحات بينها بطرق جيوديسية موثقة وشفافة، مع حفظ محلي وتصدير النتائج.

## 2) المستخدم المستهدف
مهندس نظم معلومات جغرافية (GIS) يحتاج: دقة حسابية، صيغ إحداثيات متعددة (DD/DMS/UTM/MGRS)، شفافية منهجية الحساب، وقابلية توسعة نحو حسابات مساحية أدق (Vincenty/Karney) لاحقًا.

## 6) سياسة الدقة (تُعرض في الواجهة)
- Haversine يحسب على كرة نصف قطرها 6371.0088 كم؛ الفرق عن الإهليلج WGS84 قد يصل لـ ~0.5% — يُذكر النوع مع كل نتيجة (FR-14) وسيكون الترقية لـ Vincenty/Karney جاهزة عبر Strategy.
- دقة GPS المتصفح (5–50م عادة) منفصلة عن دقة الحساب الرياضي — تعرضان منفصلتين.
- الفرق بين ارتفاعات Geoid والإهليلج: خارج النطاق حاليًا، يُدرس عند تفعيل القياسات ثلاثية الأبعاد.
